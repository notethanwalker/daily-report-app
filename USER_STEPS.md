# Remaining user steps

## Required now
1. Create a GitHub account if needed.
2. Create a PRIVATE repository named `daily-report-app`.
3. Upload the `web` and `backend` folders from this package.

## Deploy web app
4. Create a Vercel account.
5. Import the GitHub repository.
6. Set Root Directory to `web`.
7. Deploy and copy the HTTPS URL.

## Deploy backend
8. Create an account with a FastAPI/Docker host such as Render, Railway, Fly.io, or FastAPI Cloud.
9. Deploy the `backend` directory using the included Dockerfile.
10. Copy its HTTPS API URL.

## Put it on your iPhone
11. Open the HTTPS web-app URL in Safari.
12. Tap Share -> Add to Home Screen -> Add.
No Mac or Xcode is required.

## After the shell is online
13. Create primary market-data provider account.
14. Create independent secondary market-data provider account.
15. Create news provider account(s).
16. Create options/flow provider account with required exchange/data entitlements.
17. Create managed PostgreSQL database.
18. Add all credentials only as server-side environment variables.
19. Give me the provider names/URLs and I can implement the adapters in the next build pass.

## Ongoing updates
Future code changes can be pushed to GitHub and redeployed. The iPhone Home Screen PWA does not need Xcode or a Mac.
