# Daily Report PWA
Mac-free architecture: Next.js/React PWA + FastAPI backend.

## Deployment warning

Vercel Git auto-deploys are intentionally disabled. Before changing or deploying the frontend, read [`VERCEL_MANUAL_DEPLOYMENT_WORKAROUND.md`](./VERCEL_MANUAL_DEPLOYMENT_WORKAROUND.md). It documents the required helper-branch/package deployment process, cleanup steps, provenance checks, and the rule not to re-enable automatic Git deployment.
